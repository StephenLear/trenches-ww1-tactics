## Gotchas

- Don't run `expo run:ios` / local Xcode builds on this Mac: Xcode 27 SDK breaks RN 0.76 pods, and it created an `ios/` folder that had to be deleted by hand.
- CocoaPods needs `LANG=en_US.UTF-8` or it crashes on a Unicode error.
- EAS auto-increments `buildNumber` in `app.json` locally. Commit the bump after each build.
- Claude in Chrome file uploads are capped at 10 MB. Videos need re-encoding below that (the preview at 2.4 Mbps is visually identical).
- App Store Connect Media Manager: files uploaded together land in completion order, so upload one at a time or drag to reorder.
